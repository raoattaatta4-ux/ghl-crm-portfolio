## Run the web demos
Download this repository and open either HTML file in a browser. There is no build step and no external dependency.
GitHub file links display source code. Try the [live portfolio demos](https://atta-ghl-portfolio.raoattaatta4.chatgpt.site).

Optional local server from the repository folder:
```bash
python -m http.server 8000
```
Then visit:
- http://localhost:8000/lead-capture/
- http://localhost:8000/product-specifications/

## Try the interactions
- Submit the inquiry form with sample details and a service selection to see a local confirmation.
- Try missing fields and an invalid email to see browser validation.
- Use Tab and Enter/Space to expand and collapse the specification table.
- Resize the browser to check the single-column mobile layout and text wrapping.

## Scope
These are portfolio demos, not client deliverables or claims of measured business outcomes.
The form does not transmit or store data. The product values are fictional.
The workflow is a written implementation blueprint, not a GHL snapshot, live integration or executable automation.
